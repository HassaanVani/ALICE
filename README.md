# ALICE

> An AI robotics platform combining vision, logic, and hardware control for autonomous behavior.

## Overview

ALICE is a modular robotics AI system that integrates computer vision, decision-making logic, and hardware interfaces. The platform supports both autonomous operation and teleoperation (puppet mode) for training and demonstration purposes.

## Key Features

- **Computer Vision** — Real-time object detection and scene understanding
- **Logic Engine** — Decision-making system for autonomous behavior
- **Hardware Control** — Direct interface with motors, sensors, and actuators
- **Puppet Mode** — Teleoperation server for remote control and data collection
- **Taptic Integration** — Gesture-based control interface

## Tech Stack

Python, OpenCV, TensorFlow/PyTorch, Flask/FastAPI
